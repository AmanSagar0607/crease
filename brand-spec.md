# Zappa brand spec

## Identity

- **Product name:** Zappa
- **User-approved mark:** text-only “Zappa.” wordmark; no new icon or symbol.
- **Product role:** revenue and acquisition analytics for SaaS founders, indie hackers and developers.
- **Tagline:** Know what drives your growth.
- **Design mode:** Redesign · Preserve. Rebrand the existing working product; do not rename tracker wire protocols, public npm package names or event APIs.

## Assets

- **Wordmark:** Render the literal Zappa wordmark in the application UI using the existing typography; no bespoke raster/SVG logo was supplied or approved.
- **Product UI reference:** The running existing dashboard is the source for protected Zappa functionality and component vocabulary. DataFast is a behavioral/layout reference only, not an asset source.
- **DataFast screenshot:** Private `/dashboard` is access-gated; no private screenshot was accessed or copied. Refer to `docs/research/DATAFAST_REFERENCE_AUDIT.md` for observed vs unverified claims.
- **Social provider marks:** Clerk’s prebuilt sign-in components render provider controls; no third-party asset is repurposed as Zappa branding.

## Visual system

See `docs/design/ZAPPA_DESIGN_SYSTEM.md` for tokens, density, layout, motion, accessibility and responsive behavior. Dark mode is the analytics default; public marketing pages retain the existing theme toggle. Use the repository's component and icon assets; do not add a decorative logo glyph.
