# Mobbin — design-reference evidence note

**Reference:** Mobbin (design reference library, not an analytics competitor). The official homepage describes a searchable library of real mobile apps, web apps, and websites, intended to help designers and developers study screens, UI patterns, and multi-step flows. Its reference coverage includes dashboards, tables, navigation, forms, empty states, and flows; the homepage says references are from shipped products and content is added weekly.[1]

## Verifiable facts and observed patterns

- **Stated product fact:** Mobbin organizes references by screens, UI elements, flows, and website sections. Its web exploration page exposes these as separate browse categories, with collections and individual screen examples linked to related UI elements and flows.[1] [2]
- **Observed information architecture:** category browsing, tagged examples, collections, and links between screens and flows support moving from an individual component to its surrounding context. This describes the library's presentation, not a claim that any pattern performs better.[2]
- **Access facts:** Mobbin describes free access as limited and paid plans as providing fuller access; the pricing page distinguishes Free, Pro, Team, and Enterprise. Its displayed prices and feature limits can change, so verify the live pricing page before relying on specifics.[1] [3]
- **No Mobbin trust/privacy or visual-style claim is inferred here.** The sources opened establish product purpose and access tiers, not security guarantees or a required dashboard aesthetic.
